## Descripción general

### ¿Qué contiene este portafolio?
Este portafolio reúne un conjunto de actividades prácticas, evaluaciones analíticas y proyectos integradores orientados al dominio del paradigma de **Programación Orientada a Objetos (POO)**. Incluye desde exámenes prácticos contrarreloj hasta el desarrollo de aplicaciones modulares que implementan estructuras de datos abstractas, manipulación de archivos y lógica de negocio avanzada.

### Tecnologías utilizadas
Para el desarrollo de las actividades se emplearon herramientas modernas de desarrollo de software, gestión de servidores locales y control de versiones:
* **Lenguajes de Programación:** PHP, Python
* **Desarrollo Web Frontend:** HTML5, CSS3
* **Entorno de Servidor Local:** XAMPP (Apache)
* **Control de Versiones y Despliegue:** Git & GitHub

### Competencias desarrolladas
* **Abstracción y modularidad:** Capacidad para modelar entidades del mundo real en clases y objetos con responsabilidades bien definidas.
* **Persistencia de datos:** Implementación de sistemas de gestión y lectura/escritura de bitácoras en archivos de texto plano.
* **Optimización y algoritmia:** Manejo eficiente de estructuras de datos lineales como arreglos unidimensionales para la organización de la información.
* **Análisis de infraestructura:** Modelado y estimación del consumo energético en servidores mediante métodos algorítmicos.

## Lista de proyectos incluidos

A continuación se detallan las actividades de evaluación e integración que conforman el núcleo de este portafolio:

### 1. Examen contra reloj (Corte 1 Unidad 2)
* **Descripción:** Evaluación práctica de alto rendimiento diseñada para medir la velocidad de resolución de problemas, diseño de clases e implementación de lógica bajo restricciones de tiempo estrictas.

### 2. Actividad de evaluación C2 - Consumo energético servidores Unidad 3 – Métodos
* **Descripción:** Aplicación orientada al análisis de eficiencia en infraestructura tecnológica. Implementa métodos específicos para calcular, evaluar y optimizar el consumo de energía en arquitecturas de servidores.

### 3. Actividad de evaluación c3 – usuarios
* **Descripción:** Módulo de gestión y control de acceso. Incluye la definición de clases para el manejo de perfiles, propiedades, métodos de autenticación y validación de roles de usuario.

### 4. Actividad Integradora - Arreglos unidimensionales
* **Descripción:** Proyecto enfocado en la manipulación de colecciones de datos. Implementa operaciones fundamentales de inserción, ordenamiento, búsqueda y filtrado de objetos estructurados dentro de vectores secuenciales.

### 5. Actividad Integradora - Gestión de Bitácoras en Archivos de Texto
* **Descripción:** Sistema de persistencia ligera enfocado en la administración de registros y logs del sistema. Permite la escritura incremental, lectura estructurada y parseo de bitácoras almacenadas directamente en archivos físicos de texto.
